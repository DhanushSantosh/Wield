# Code of conduct

Wield adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space — issues, pull requests, reviews, discussions, and any other channel where you represent the project.

In short: be respectful and constructive, assume good faith, and keep criticism focused on the work. Harassment, personal attacks, discriminatory language, and publishing someone's private information are not acceptable.

## Reporting

Report conduct problems privately to the maintainer, @DhanushSantosh. GitHub has no direct messages, so use the [private reporting form](https://github.com/DhanushSantosh/Wield/security/advisories/new) and start the title with "Conduct report:". Only the maintainer can read these reports. Do not report conduct issues in public threads.

## Enforcement

The maintainer reviews every report and decides on a response, following the Contributor Covenant's enforcement guidelines: a private correction, a warning, a temporary ban, or a permanent ban, depending on severity and history. The reporter's identity is kept private.
